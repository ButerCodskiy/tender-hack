# Frontend — Портал поддержки поставщиков

Веб-интерфейс интеллектуальной службы поддержки пользователей Портала поставщиков г. Москвы.

## Режимы запуска

Фронтенд поддерживает два режима работы, управляемых флагом **`VITE_STANDALONE`**:

### 1. Автономный визуальный режим (Чисто визуал, без API и БД)
Работает полностью автономно в браузере. Все сетевые запросы к API и базе данных заменяются локальной интерактивной эмуляцией:
- Потоковые ответы ИИ с ранжированием и цитированием регламентов Портала (44-ФЗ, котировочные сессии, КриптоПро, МЧД, протоколы разногласий).
- Вход в один клик под любой из трех ролей (Поставщик/Клиент, Оператор 1-й линии, Супервизор).
- Вызов оператора (эскалация) и подтверждение решения тикета с CSAT-оценкой.
- Полнофункциональное рабочее место оператора (АРМ): статус смены, список тикетов, панель Копилота с рекомендациями и базой знаний, отправка сообщений, перевод на L2.

**Команда запуска:**
```bash
npm run dev:standalone
# или
npm run dev:mock
```

**Сборка автономной статической версии:**
```bash
npm run build:standalone
```

---

### 2. Режим работы с бэкендом (API + БД)
Фронтенд проксирует запросы к реальному FastAPI бэкенду (`http://127.0.0.1:8000`), подключенному к PostgreSQL, Redis и Qdrant.

**Команда запуска:**
```bash
npm run dev:api
# или стандартная команда (при VITE_STANDALONE=false)
npm run dev
```

**Сборка для продакшена:**
```bash
npm run build
```

---

## Способы задания флага

| Способ | Пример | Описание |
|---|---|---|
| **NPM скрипт** | `npm run dev:standalone` | Автоматически подгружает `.env.standalone` (`VITE_STANDALONE=true`) |
| **NPM скрипт** | `npm run dev:api` | Автоматически подгружает `.env.development` (`VITE_STANDALONE=false`) |
| **Файл `.env`** | `VITE_STANDALONE=true` в `frontend/.env` | Применяется ко всем стандартным командам `npm run dev` |
| **URL-параметр** | `http://localhost:5173/?mode=standalone` или `?mode=api` | Мгновенное переключение прямо через адресную строку браузера |
| **Кнопка в UI** | Бейдж в боковой панели или на странице входа | Переключение между «Автономный» и «API» в один клик без перезапуска |
| **Docker Compose** | `VITE_STANDALONE=true docker compose up --no-deps frontend` | Запуск только контейнера фронтенда без поднятия тяжелых сервисов БД/API |

---

## Конфигурационные файлы
- `.env.standalone` — `VITE_STANDALONE=true`
- `.env.development` — `VITE_STANDALONE=false`, `VITE_BACKEND_URL=http://127.0.0.1:8000`
- `.env.example` — шаблон с описанием переменных
