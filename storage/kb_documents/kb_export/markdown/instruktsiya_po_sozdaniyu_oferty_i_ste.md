# Введение

Настоящая инструкция описывает процесс создания поставщиком оферт и СТЕ на Портале поставщиков.

В инструкции описаны следующие способы добавления оферт:

* подача ценового предложения на основе СТЕ;
* загрузка файлов в форматах YML и XLSX;
* создание предложения и СТЕ через экранную форму;
* создание оферт на основе КС.

Кроме того, в инструкции содержится подробное описание по работе с офертами, в том числе по офертам, созданным на основе КС.

# 1. Подача ценового предложения

Если СТЕ имеет вариативность, то ценовое предложение будет создано только для того варианта СТЕ, с которого была нажата кнопка «Опубликовать предложение».

Если необходимая СТЕ уже размещена в Каталоге ТРУ, поставщику достаточно создать ценовое предложение на ее основе. Для этого в Каталоге ТРУ выберите нужный товар, перейдите в его карточку, нажмите «Действия с СТЕ и офертами» и в открывшемся списке выберите «Опубликовать предложение» (Рисунок 1).

Импорт прайс-листов можно осуществить двумя способами:

* через YML прайс-листы;
* через формат XLSX. Формат XLSX позволяет только обновить ценовые предложения в уже существующих позициях каталога. Процесс загрузки файла аналогичен процессу загрузки YML прайс-листов. Для формирования файла формата XLSX необходимо из раздела с офертами выгрузить необходимые оферты и изменить требуемые данные (срок действия, стоимость и т.д.).

Для загруженных оферт возможен поиск по следующим параметрам (Рисунок 8):

* «Дата загрузки с» и/или «Дата загрузки по»;
* Статус: «В очереди», «Обработка», «Ошибка при обработке», «Завершена успешно», «Завершена с ошибками», «Ошибка входных данных», «Отменено пользователем», «Проверка данных»:
    * «В очереди» – файл находится в очереди на загрузку;
    * «Обработка» – файл обрабатывается;
    * «Ошибка при обработке» – файл загружен с ошибками;
    * «Завершена успешно» – загрузка файлов завершена;

* указывать единицы измерения характеристик в отдельном поле «Единицы измерения» (исключения – в существующих характеристиках не указана единица измерения или у характеристики не может быть единицы измерения). Единицу измерения необходимо добавлять в том случае, если используются числовые значения;
* максимально подробно описывать товар/работу/услугу. Для описания товара необходимо указывать технические, физические, эксплуатационные и иные характеристики товара. В качестве
