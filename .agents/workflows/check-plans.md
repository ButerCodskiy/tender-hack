# Автоматическая проверка планов

## Контекст

Этот workflow анализирует все планы в `notes/plans/active/` и проверяет, выполнены ли задачи в коде проекта. Обновляет чекбоксы:
- `[x]` — задача полностью реализована
- `[/]` — задача частично выполнена или неоднозначна
- `[ ]` — задача не выполнена

## Step 1: Найти активные планы

Найди все `.md` файлы в `notes/plans/active/`.

Если планов нет — выведи: "Активные планы не найдены. Переместите планы из `drafts/` в `active/`."

## Step 2: Проанализировать и обновить планы

Для каждого плана:

1. **Прочитай план** и найди все чекбоксы
2. **Проверь каждую задачу** — реализована ли она в коде
3. **Обнови статус чекбокса**:
   - Если задача полностью реализована → `[x]`
   - Если частично или неясно → `[/]`
   - Если не реализована → `[ ]`
4. **Сохрани обновлённый план**

При проверке учитывай:
- Наличие файлов, функций, классов из задачи
- Реальная реализация, а не просто `pass` или `TODO`
- Наличие тестов, если они упомянуты

## Step 3: Показать итоговый отчёт

Выведи статистику по всем проверенным планам:

```
📊 Статистика проверки планов

Проверено планов: 2

План: microservices-shop-completion-09-02-2026-plan.md
  ✅ Завершено: 12
  🔄 В процессе: 5
  ❌ Не начато: 3

План: error-handling-03-02-2026-plan.md
  ✅ Завершено: 8
  🔄 В процессе: 2
  ❌ Не начато: 1

Общий прогресс: 64% завершено
```

## Результат

Все активные планы обновлены с актуальными статусами задач на основе анализа кода.
