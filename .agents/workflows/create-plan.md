# Создание плана для ИИ агента

## Сохранение
Файл: `notes/plans/drafts/<тема>-DD.MM.YYYY-plan.md`.

## Порядок реализации
Пиши код снизу вверх:
1. Модели и схемы БД
2. Репозиторий
3. Сервис
4. Эндпоинт
5. ✅ Проверка

## Принципы
1. **Этап = проверяемый результат.** После каждого этапа выписывай чеклист для ручной проверки (команды для терминала, запросы через curl, или шаги для визуального тестирования в Swagger/Postman).
2. **Цель этапа.** Начинай этап с описания того, что должно заработать.

## Шаблон

```markdown
# План: [Название]

> **Цель проекта:** [Кратко]

### Этап 1: [Что заработает]

> **Цель:** [1 предложение]

- [ ] Модели/БД...
- [ ] Репозиторий...
- [ ] Сервис...
- [ ] Эндпоинт...
- [ ] ✅ Проверка:
  - [ ] Как проверить: [команда, тест или действия в Swagger/UI]
  - [ ] Ожидаемый результат: ...

### Этап 2: [Название]
...
```

## Чекбоксы
`[ ]` → `[/]` → `[x]`. Обновляй после выполнения задачи.
