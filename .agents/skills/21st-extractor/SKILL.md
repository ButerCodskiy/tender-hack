# 21st.dev Autonomous Universal Extractor & Scout

Автономный поиск и извлечение всех 3 типов ресурсов с `21st.dev` без авторизации и API-ключей:
1. **UI Components (`/components/...`):** чистый демо-код + скомпилированный бандл (Framer Motion, подкомпоненты).
2. **Templates (`/templates/...`):** прямая ссылка на открытый GitHub-репозиторий и Live Preview.
3. **Themes (`/themes/...`):** полная палитра CSS-переменных (`:root`, `.dark`) для Tailwind и shadcn/ui.

---

## Механика работы
1. **Компоненты (`/components/`):** метаданные и зависимости извлекаются через `.md`, демо-код — с `cdn.21st.dev/.../code.demo.tsx`, а полная имплементация — из `bundle.html` с `Referer: https://21st.dev/`.
2. **Шаблоны (`/templates/`):** извлекаются прямые ссылки на открытый GitHub-репозиторий и интерактивное Live Preview проекта.
3. **Темы оформления (`/themes/`):** извлекаются полные токены цветов для светлой и темной тем через tRPC API `themes.getBySlug`.

## 2. Алгоритм извлечения кода

Для извлечения чистого кода и зависимостей по URL компонента используйте встроенный скрипт навыка:

```bash
python .agent/skills/21st-extractor/scripts/extract_component.py <URL_КОМПОНЕНТА>
```

### Программная логика скрипта:
1. **Запрос зависимостей:** `GET https://21st.dev/<author>/components/<slug>.md` → извлечь строку после `npm dependencies:`.
2. **Умный парсинг CDN ссылок:** Извлечение всех `https://cdn.21st.dev/...` из JSON потока Next.js.
3. **Запрос бандла:** Скачивание бандла логики `.html` и демо-кода `.tsx` с CDN, извлечение полной логики компонента, вариантов анимаций Framer Motion и подкомпонентов.
---

## 3. Как агенту работать с результатом экстрактора (Декомпиляция в чистый TSX)

При запуске скрипта агент получает структурированный вывод из двух ключевых частей:
1. **Секция 3 (Usage & Demo Code):** Демонстрационный код вызова компонента (импортирует `@/components/ui/...`).
2. **Секция 4 (Compiled Component Implementation):** Полная логика самого компонента, включая Framer Motion анимации, хуки, физику и все дочерние подкомпоненты, извлеченная из живого бандла превью.

### Обязательный алгоритм действий агента:
1. **Создать файл компонента:** `src/components/ui/<component-name>.tsx`.
2. **Восстановить чистый JSX/TSX из Секции 4:**
   * Преобразовать скомпилированные вызовы `ct.jsx(tag, { className: '...', children: ... })` в стандартный читаемый JSX `<tag className="...">...</tag>`.
   * Задать понятные имена подкомпонентам и типам пропсов (например, `NavItem`, `WorkspaceSelector`, `FloatingDockProps`).
   * Добавить `"use client";` в начале файла при использовании хуков (`useState`, `useEffect`, `useRef`, Framer Motion).
3. **Использовать код из Секции 3:**
   * Вставить демо-код или адаптировать его под конкретную страницу проекта, импортируя только что созданный компонент из `src/components/ui/<component-name>.tsx`.

## 4. Паттерн внедрения компонента в проект

1. **Установка пакетов:**
   ```bash
   npm install clsx tailwind-merge framer-motion lucide-react @tabler/icons-react
   ```
   *(Использовать только фактически требуемые компонентом пакеты).*

2. **Проверка утилиты объединения классов (`src/lib/utils.ts`):**
   ```typescript
   import { ClassValue, clsx } from "clsx";
   import { twMerge } from "tailwind-merge";

   export function cn(...inputs: ClassValue[]) {
     return twMerge(clsx(inputs));
   }
   ```

3. **Адаптация под Tailwind v4:**
   * Убедиться в отсутствии устаревших классов Tailwind v3.
   * Конфигурацию цветов и анимаций вносить через `@theme` в `src/index.css` (а не в `tailwind.config.js`).
