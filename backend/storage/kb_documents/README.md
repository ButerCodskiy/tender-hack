# Каталог входящих документов базы знаний (Knowledge Base Ingestion)

Поместите сюда спаршенные регламенты, методички и таблицы от организаторов хакатона:
- **PDF-документы:** регламенты котировочных сессий, инструкции по ЭЦП КриптоПро, регламенты Портала поставщиков.
- **DOCX-документы:** методические указания, регламенты взаимодействия.
- **XLSX / CSV-таблицы:** таблицы FAQ (вопрос-ответ), классификаторы ошибок.
- **Markdown-файлы (.md):** структурированные спаршенные статьи.

После добавления файлов запустите парсинг и векторизацию в Qdrant:
```powershell
uv run python -m src.kb.cli ingest --dir storage/kb_documents
```
