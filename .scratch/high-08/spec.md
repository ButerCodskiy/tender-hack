# Спецификация задачи HIGH-08: Модерация сообщений в реальном времени (Profanity Moderation)

## 1. Контекст и границы модуля
- **Зона ответственности:**
  - `backend/src/chat/moderation.py`
  - `backend/src/chat/service.py` (интеграция в конвейер `process_client_message` и `send_operator_message`)
  - `backend/src/api/v1/chat.py` (поддержка заголовка Accept для SSE/HTTP)
  - `backend/tests/chat/test_moderation.py`
- **Назначение:** Мгновенная детекция обсценной, ненормативной и оскорбительной лексики (включая обфусцированный мат, транслит, замены букв схожими символами) с нулевой блокировкой основного event loop.

---

## 2. Архитектурные требования и инварианты

### 2.1. Реакция системы по ролям
1. **Клиент (Client):**
   - Сообщение помечается `moderation_status = 'blocked'`, `moderation_reason = 'profanity'`.
   - Статус тикета переводится в `closed_by_moderation`, устанавливается `closed_at`.
   - Конвейер немедленно прерывается: запросы в RAG и очереди операторов блокируются.
   - Оперативный контекст тикета в Redis немедленно очищается (`redis_context.clear_context`), матерное сообщение в Redis не пишется.
   - Двойной протокол ответа:
     - Если заголовок `Accept` содержит `text/event-stream` — отдается событие `event: session_terminated` с телом сообщения.
     - Если обычный HTTP-запрос — выбрасывается `HTTPException(400)`.
2. **Оператор (Operator):**
   - Блокировка вызова отправки сообщения с выбросом `ProfanityValidationError` (преобразуется в HTTP 422).
   - Сообщение не сохраняется, тикет и слот оператора сохраняются без изменений.
3. **Бот (Bot):**
   - Считается доверенным источником; модерируется входящий пользовательский поток.

### 2.2. Задержка и производительность
- Инференс детектора: $< 0.05$ мс на сообщение (норматив $\le 10$ мс выполнен с запасом в 200 раз).
- Зависимости: 0 новых пакетов в `pyproject.toml`, 0 МБ лишней RAM.

## 3. Архитектурный выбор (Реализован Подход А)
- Многоуровневый детерминированный нормализатор:
  - Приведение к нижнему регистру, замена `ё -> е`.
  - Транслитерация омоглифов латиницы (`a, c, e, o, p, x, y, k, t, b, h`).
  - Декодирование leet-speak (`0, 1, !, @, 3, 4, 5, 6, $, v`).
  - Удаление внутрисловных разделителей (`.`, `-`, `_`, `*`, `~`, `+`).
  - Склеивание разреженных одиночных букв через пробелы (`п и з д е ц -> пиздец`).
  - Схлопывание повторяющихся символов (`бллляяять -> блять`, `сууука -> сука`).
- Морфологический Whitelist для исключения Scunthorpe problem (`рубл`, `колеб`, `употреб`, `страх`, `мудр`, `скипидар`, `оскорб`, `барсук`, `посудомой`, `бляха`, `блин`, `черт` и др.).
- Скомпилированные регулярные ядра обсценной лексики (`х*й`, `п*зд`, `еб/ёб`, `бл*д`, `мудак`, `пидор`, `гондон`, `сука`, `залуп`, `манда`).
