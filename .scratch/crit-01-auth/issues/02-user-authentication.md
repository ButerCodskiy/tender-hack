# 02: Аутентификация пользователя и обновление пары токенов

**What to build:** Возможность для любого зарегистрированного пользователя войти в систему по адресу электронной почты и паролю, получив действующую пару токенов (кратковременный access-токен и долгоживущий refresh-токен), а также обменять валидный refresh-токен на новую пару токенов при завершении срока действия предыдущей сессии.

**Blocked by:** 01: Регистрация клиента с созданием профиля и постоянного чата

**Status:** resolved

- [x] Эндпоинт `POST /api/v1/auth/login` проверяет учетные данные пользователя и при успехе возвращает статус `200 OK` с токенами и профилем.
- [x] При неверном адресе электронной почты или ошибочном пароле сервер возвращает унифицированную ошибку `401 Unauthorized` без уточнения существования учетной записи.
- [x] При попытке входа пользователя с деактивированной учетной записью возвращается ошибка `403 Forbidden`.
- [x] Эндпоинт `POST /api/v1/auth/refresh` принимает действующий refresh-токен, проверяет его валидность и срок действия и возвращает новую пару токенов со статусом `200 OK`.
- [x] При передаче невалидного или истекшего refresh-токена сервер возвращает `401 Unauthorized`.
- [x] Реализованы автоматические тесты сценариев аутентификации, блокировки деактивированных пользователей и обновления токенов.
