# 01: Регистрация клиента с созданием профиля и постоянного чата

**What to build:** Возможность для нового клиента (поставщика) зарегистрироваться в системе, передав учетные данные (адрес электронной почты, пароль) и опциональные реквизиты организации (наименование, ИНН, КПП, телефон). Сервер сохраняет учетную запись и профиль организации, автоматически создает постоянный чат поддержки и возвращает пару токенов доступа вместе с профилем пользователя.

**Blocked by:** None (can start immediately)

**Status:** resolved

- [x] Эндпоинт `POST /api/v1/auth/register` принимает данные регистрации, проводит валидацию (формат email, длина пароля не менее 8 символов, длина ИНН 10 или 12 знаков) и возвращает статус `201 Created` со структурой токенов и профиля.
- [x] Пароль сохраняется в базу данных исключительно в виде криптографического хеша; открытый пароль не логируется и не хранится.
- [x] Сущности пользователя и профиля сохраняются с первичными ключами UUID версии 7.
- [x] Для зарегистрированного клиента создается начальная сущность долгоживущего чата поддержки.
- [x] При повторной регистрации с тем же адресом электронной почты возвращается ошибка со статусом `409 Conflict`.
- [x] Реализованы автоматические тесты успешной регистрации, отказа при дубликате почты и валидации реквизитов.
