# 03: Защищенный профиль пользователя и зависимость аутентификации

**What to build:** Возможность для аутентифицированного пользователя получить данные своего профиля, а для прикладных обработчиков платформы — надежно защищать закрытые маршруты и извлекать контекст пользователя из заголовка Authorization через централизованную зависимость FastAPI.

**Blocked by:** 02: Аутентификация пользователя и обновление пары токенов

**Status:** resolved

- [x] В `src/api/dependencies.py` реализована централизованная зависимость аутентификации, извлекающая и валидирующая Bearer JWT-токен из заголовка `Authorization`.
- [x] При отсутствии заголовка, нарушении подписи токена или истечении срока его действия запрос отклоняется со статусом `401 Unauthorized`.
- [x] Если учетная запись пользователя деактивирована, доступ отклоняется со статусом `403 Forbidden`.
- [x] Эндпоинт `GET /api/v1/auth/me` возвращает профиль текущего пользователя со всеми реквизитами организации и кодом роли со статусом `200 OK`.
- [x] Реализованы автоматические тесты доступа к защищенному маршруту: успешный ответ с валидным токеном, отказ при невалидном токене и отказ при отсутствии заголовка.
