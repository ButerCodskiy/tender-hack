# Задача 01: Детерминированный L1-фильтр чувствительных тем

Status: resolved
Blocked by: none

## Описание
Разработать класс `SensitiveTopicsGuardrail` в `backend/src/chat/moderation.py`:
1. Нормализация текста (деобфускация омоглифов, leet-speak, схлопывание точек и спецсимволов внутри слов).
2. Скомпилированные регулярные выражения для политики, религии, наркотиков/прекурсоров, медицины/суицида, оружия/экстремизма.
3. Whitelist для легитимных закупок по 44-ФЗ/223-ФЗ (лекарства, перчатки, шприцы, СТЕ).
4. Метод `check_sensitive_topics(text: str) -> SafetyCheckResult`.

## Результат
Реализован в `backend/src/chat/moderation.py`. Покрыт 40 сценариями в тестовом сьюте. Латентность < 0.5 мс, FPR = 0%.
