# ADR: Выбор моделей LLM и Embedder под бюджет VRAM 8 GB (AMD Radeon RX 6600)

* **Статус:** Принято (Accepted)
* **Дата:** 2026-09-12
* **Аппаратная платформа:** AMD Radeon RX 6600 (8 GB VRAM, архитектура RDNA 2, Navi 23 / gfx1032), Windows 10/11
* **Цель:** Обеспечение локального инференса генеративного RAG и пакетной индексации без превышения лимита видеопамяти.

---

## 1. Контекст и ограничения памяти

Видеокарта **AMD Radeon RX 6600** обладает физическим объемом видеопамяти **8192 МБ (8 ГБ)**.
Для одновременной или последовательной работы сервисов необходимо строго распределить квоты VRAM, исключив риск OOM (Out Of Memory) и переключения на медленный shared memory (swap в системную RAM):

1. **Системный резерв ОС / DWM:** ~800–1000 МБ.
2. **Доступно для ML-пайплайна:** ~7000–7200 МБ.

---

## 2. Архитектурное решение

### 2.1. Embedding Model: `BAAI/bge-m3` (1024D)
- **Назначение:** Двухканальная векторизация дочерних чанков регламентов и входящих запросов пользователей.
- **Размерность:** 1024 float32 (dense vector).
- **Рантайм и бэкенд на AMD GPU:**
  - **Первичный:** `fastembed` с бэкендом `DirectML` (`onnxruntime-directml` через DirectX 12). Прямое аппаратное ускорение на чипах RDNA 2 в Windows без зависимости от ROCm.
  - **Вторичный / Сервисный:** `Ollama` (`bge-m3`) с переменной среды `HSA_OVERRIDE_GFX_VERSION=10.3.0`.
- **Потребление VRAM:** 1.2–1.8 ГБ.

### 2.2. Генеративная LLM: `qwen2.5:7b-instruct-q4_k_m`
- **Назначение:** Генерация финальных ответов операторам и клиентам, суммаризация контекста, строгое цитирование регламентов сносками вида `[^1]`.
- **Квантование:** Q4_K_M (оптимальный баланс перплексии и экономии памяти для инструктивных моделей).
- **Контекстное окно:** до 32k токенов (рабочее окно RAG: 4k–8k токенов).
- **Рантайм:** `Ollama for Windows` с драйвером ROCm и флагом `HSA_OVERRIDE_GFX_VERSION=10.3.0`.
- **Потребление VRAM:** ~4.5–4.8 ГБ (веса) + 500–800 МБ (KV-кэш для контекста 4k).

### 2.3. Fallback-модель: `qwen2.5:3b-instruct-q4_k_m`
- **Назначение:** Аварийный режим при экстремальной нагрузке или параллельном запуске нескольких задач.
- **Потребление VRAM:** ~2.1 ГБ.

---

## 3. Сводный бюджет VRAM (VRAM Budget Matrix)

| Компонент | Модель / Сервис | Потребление VRAM | Примечание |
| :--- | :--- | :--- | :--- |
| **DWM / ОС Windows** | Desktop Window Manager | ~800 МБ | Базовая загрузка монитора |
| **Embeddings** | `BAAI/bge-m3` (DirectML/ONNX) | ~1 400 МБ | Пакетный инференс (batch=32) |
| **LLM Inference** | `qwen2.5:7b-instruct-q4_k_m` | ~4 700 МБ | Полный перенос слоев на GPU |
| **KV-Cache / Context** | 4096 токенов | ~600 МБ | Динамическое выделение |
| **ИТОГО:** | **Пиковая нагрузка** | **~6 900 МБ / 8 192 МБ** | **Запас: ~1.2 ГБ свободной VRAM** |

---

## 4. Конфигурация запуска

```powershell
# 1. Активация аппаратной совместимости RDNA 2 (gfx1032)
[System.Environment]::SetEnvironmentVariable('HSA_OVERRIDE_GFX_VERSION', '10.3.0', 'User')
$env:HSA_OVERRIDE_GFX_VERSION = "10.3.0"

# 2. Запуск Ollama
ollama serve

# 3. Загрузка моделей
ollama pull qwen2.5:7b-instruct-q4_k_m
ollama pull bge-m3
```
